## Статистика VCF

50 уникальных биаллельных SNV: 16 на хромосоме 21 и 34 на хромосоме 22. Транзиций A↔G и C↔T: 40; трансверсий: 10; Ti/Tv = 4.

Поля VCF: CHROM - хромосома; POS - позиция от 1; ID - идентификатор; REF/ALT - аллели; QUAL - качество вызова; FILTER - фильтры; INFO - дополнительные аннотации. Точка означает отсутствие значения. QUAL/FILTER/INFO не заполнены; FORMAT и генотипов в файле нет.

## Правила аннотации

Ensembl VEP release 116, Homo sapiens, GRCh38. Включены canonical, MANE, HGVS, protein, transcript_version и variant_class. Фильтры транскриптов и VEP --pick не применялись.

В сводную таблицу взято most_severe_consequence по всем транскриптам. Среди транскриптов с этим последствием приоритет: MANE Select → canonical → protein_coding → лексикографически первый transcript_id. Поля gene, HGVS и impact относятся к выбранному транскрипту. all_vep_genes может включать гены соседних upstream/downstream-транскриптов; это не означает причинной связи со всеми перечисленными генами. Все альтернативные аннотации находятся в экспорте VEP.

ClinVar: объединены поиски по rsID и координатам chrpos38. Кандидаты строго проверены по GRCh38 + CHROM + POS + REF + ALT. Точных совпадений: 17; без точной записи: 33. not_found означает отсутствие точного совпадения после успешного поиска и не является классификацией доброкачественности. Review status, условия и отдельные утверждения сохранены в результатах ClinVar.

Варианты VUS и записи evidence_only обозначены отдельно. evidence_only означает наличие сведений без клинической классификации; это не отсутствие записи и не VUS.

gnomAD: dataset gnomad_r4, GRCh38; сопоставление по CHROM-POS-REF-ALT. AF - глобальная частота ALT, вычисляемая как AC/AN; это не обязательно частота минорного аллеля. Экзомы и геномы представлены раздельно, без сложения когорт. Пустой список фильтров API обозначен PASS. Минорная версия gnomAD не возвращается использованным запросом и не заявляется. not_found относится к выбранному набору r4; недоступная частота обозначена NA, а не нулём.

NA означает, что источник не предоставил значение. Числовой ноль используется только для реального нулевого значения.

В основной таблице сохранены ссылки на варианты в Ensembl, ClinVar и gnomAD. Разбор трёх вариантов и ограничения интерпретации приведены в отчёте. Настройки и правила аннотации сохранены в annotation_settings.json.
